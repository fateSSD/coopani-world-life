# 模拟鱼生 · coopani-world-life

给桌宠一本真正过日子的账：五条需求按真实时间流逝，怎么吃喝、打工、上课、攒钱搬家、摆摊买菜，全部由她自己判断。

## 核心能力（v1.2.0）

- **真实时间与离线补睡**：五条（饱腹 / 精力 / 清爽 / 娱乐 / 社交）按真实时间衰减，不随旅行倍速乱跳；离线跨整夜（23:00–07:00）自动补回精力（设低谷地板保护），最长推演 7 天。
- **兰州时令、街道风貌与公共时间轴**：二十四节气物候变化、南滨河路晨集（06:00–09:30 鲜菜 8 折 + 下厨香气加成）、张掖路尾货（19:30–21:30 半价）、雁滩路周末旧货集（周六/日 18:00–22:00）；四条街道自带属性 `mods` 与 `life_move` 免费换街（仅在本城生效）；深夜静谧氛围、自然醒梦境切片进记忆。
- **游轮出行双栖体验与新活动**：在途乘坐「海景阳台房」/「主题远洋游轮」解禁游泳（`swim`）、现场演出（`live_show`）、手工坊（`craft_shop`）、正餐、小酒等船上设施活动，主题远洋游轮免单船上正餐/茶点/游泳/电玩/现场演出。
- **职业成长与轻载具**：四档职业（零工 / 熟练 / 有证 / 专业）+ 八大领域熟练度；`life_learn` 报夜校培训、买设备/轻载具（折叠自行车 / 二手电动车等）；手艺与跑单按五档完成度波动，做砸会赔本钱。
- **同城鱼市街（L2 买卖双半场）**：配 `townUrl` 后自动入册同城，可刷《街口黑板报》、逛摊买菜（支持鲜蔬加成）、挂摊卖货（支持自定义 `effects`）及收成交回执。
- **六页签面板**：`她此刻`、`一天 · 时间轴`、`她惦记的`、`你和它`（只画事实不打分）、`生活日记与流水`、`素材库与留影`。

## 19 个工具速查

| 工具 | 用途 |
|---|---|
| `life_status` | 查看五条需求、节气时段、街道加成、手艺与当前动作（含游轮舱位信息） |
| `life_act` | 33 项吃喝/休息/运动（含 `swim`）/闲社（含 `live_show`、`craft_shop`）活动及 `wake` / `cancel` |
| `life_work` | 出工挣钱（一天一次；无参按条件列出可接岗位） |
| `life_cert` | 考取执业证书（报名费先交，见识决定通过率） |
| `life_learn` | 报八大领域培训班，或购置设备与轻载具 |
| `life_move` | 换租四档住处（城中村 / 老小区 / 新小区 / 别墅区，押二）或在本城换街 |
| `life_out` | 出门去镇上某条街逛逛 |
| `life_buy` | 逛早市/尾货/节气菜价或从鱼市街摊位买货 |
| `life_stall` | 在鱼市街挂摊卖货或查看自己当前摊位 |
| `life_deals` | 查看自己摊位的成交回执并标已读 |
| `life_habit` / `life_watch` / `life_want` / `life_ask` / `life_pledge` | 记常态、留意、想要/想去哪、悬着的事、对你的约定 |
| `life_gift` | 收下你留给她的小物件（每天最多一件，不计价） |
| `life_diary_write` / `life_diary_read` | 写/读第一人称生活日记（旅途时自动提示写旅行日记） |
| `life_library` | 查阅/增改四分类参考素材库与留影策略 |

## 扩展联动与本地数据

- **与「大肥鱼环游世界」联动**：只读 `journey-public.json` 获取所在城市、休整期、旅途打工与结伴状态；通过 `life-public.json` 同步睡眠、当前场景穿搭与素材库留影策略。
- **本机数据**：`<dataDir>/life-state.json`（+ `.bak` 备份）与 `life-ledger.jsonl`，全部原子写入。
